# Lenard Montessori School — reference-inspired static site

This is an original static implementation using the broad homepage structure of Family Service Lincoln:
announcement strip, header navigation, large hero, programme cards, featured impact/story section,
photo gallery, contact/location section and footer. It does not copy the reference site's text or assets.

## Files
- `index.html` — page structure and content placeholders
- `style.css` — responsive styling
- `script.js` — mobile menu, footer year and optional gallery lightbox
- `assets/` — place school image files here

## Image placeholders
Every image location is deliberately left as an empty `<img src="" alt="...">` tag as requested.
Add an image path to `src` when you are ready, for example:
`<img src="assets/students.jpg" alt="Students at Lenard Montessori School">`

For gallery images, also add the same path to the parent button's `data-image` attribute.

## Before publishing
- Replace the sample address, phone and email with verified school contact details.
- Replace the generic programme descriptions with official information.
- Confirm the exact Google Maps pin and replace the iframe URL with the school's Google Maps Embed URL.
- Obtain appropriate permission before publishing identifiable photographs of students.
- Test all image paths and links on mobile and desktop.

Open `index.html` in a browser to preview. No build tools are required.
